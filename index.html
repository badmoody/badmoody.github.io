🖼️ Galeri Gambar + AI Tanya-Jawab

Tempel (Ctrl+V) link di mana saja pada halaman, seret link ke sini, atau pakai ?img=LINK di URL: gambar akan langsung tampil dan AI otomatis menjawab pertanyaan standar.

Pengaturan

Google Form (penyimpanan hasil)
Cara cepat menyiapkan
  1. Buat Google Form dengan 2 pertanyaan Jawaban singkat/Paragraf: “Link gambar” dan “Hasil QA”.
  2. Menu ⋮ → Dapatkan link isi otomatis, isi dummy, klik Dapatkan link, salin. Angka entry.xxxx di link itu adalah Entry ID.
  3. Tempel URL form dan kedua Entry ID di atas. Setiap gambar baru + hasil AI akan terkirim otomatis.
  4. Mode proxy: backend menerima {imageUrl, question} dan mengembalikan {answer}.
Catatan: token disimpan di browser ini saja. Untuk produksi, lebih aman memakai backend/proxy sendiri agar token tidak terekspos.
